## 📌 Project Overview

**Cat vs Dog Image Classification Using CNN** is a deep learning project that classifies images into two categories: **Cat** and **Dog** using a **Convolutional Neural Network (CNN)**.

The project follows an end-to-end image classification workflow, including image preprocessing, dataset preparation, CNN architecture design, model training, validation, and performance evaluation. The model learns spatial features such as edges, textures, shapes, and patterns directly from images to distinguish between cats and dogs.

### 🎯 Objective

The objective is to build a CNN model capable of automatically identifying whether a given input image contains a **cat or a dog**.

### 📊 Model Evaluation

The model is evaluated using:

* Training accuracy
* Validation accuracy
* Training loss
* Validation loss
* Confusion matrix

Training and validation curves are also analyzed to identify potential **overfitting or underfitting**.

### 💡 Key Learning

This project demonstrates how CNNs automatically learn hierarchical visual features from raw images and use these learned representations for binary image classification.

It also provides practical experience with the complete deep-learning workflow:

**Raw Images → Preprocessing → CNN → Training → Evaluation → Prediction**
